Automated Data Ingestion & Profiling Engine

Curriculum Module: 01 — Intro to Data Science • Stack: Python, Pandas, NumPy

An end-to-end computational pipeline that automates the ingestion of heterogeneous raw file formats (CSV, JSON, Excel, and Parquet), validates schema contracts, detects null/outlier anomalies, calculates empirical moments (mean, variance, skewness), and generates an executive data dictionary.

Core Architecture & Deliverables:
  • Multi-format ingestion pipeline with automated delimiter inference
  • Vectorized statistical profiling across numerical and categorical features
  • Automated missing value quantification and duplicate detection
  • Data schema export for downstream machine learning readiness
import pandas as pd
import numpy as np

def automated_data_profiler(file_path):
    # Load dataset with pandas
    df = pd.read_csv(file_path)
    
    # Statistical synthesis report
    profile = {
        "total_rows": len(df),
        "total_columns": len(df.columns),
        "null_counts": df.isnull().sum().to_dict(),
        "memory_usage_mb": df.memory_usage(deep=True).sum() / 1024**2,
        "numeric_summary": df.describe().to_dict()
    }
    print(f"[SUCCESS] Profiled {profile['total_rows']} records across {profile['total_columns']} features.")
    return profile

🔍 DS PROGRAM 2 · MODULE 02 Subject Code: 22DS102006

Multi-Source Review Scraper & Clean ETL Pipeline

Curriculum Module: 02 — Data Extraction & Wrangling • Stack: BeautifulSoup4, Requests, Pandas, SQLite

A robust web data extraction and wrangling pipeline designed to harvest product reviews, navigate DOM trees via CSS selectors, sanitize raw HTML markup, remove boilerplate stopwords, handle pagination with exponential backoff, and load clean records into a relational database.

Core Architecture & Deliverables:
  • Session-based HTTP parsing with customized User-Agents and rate limiting
  • DOM tree extraction for titles, star ratings, review timestamps, and body text
  • Automated text cleaning: Regex tokenization, stopword filtering, casing normalization
  • Structured relational database export to SQLite using SQLAlchemy and Pandas
from bs4 import BeautifulSoup
import requests
import pandas as pd

def harvest_and_clean_reviews(html_source):
    soup = BeautifulSoup(html_source, 'html.parser')
    records = []
    for item in soup.select('.review'):
        title = item.select_one('.review-title').get_text(strip=True)
        rating = item.select_one('.rating').get_text(strip=True)
        text = item.select_one('.review-text').get_text(strip=True)
        records.append({'title': title, 'rating': rating, 'text': text})
    
    df = pd.DataFrame(records)
    df.to_csv('product_reviews_cleaned.csv', index=False)
    return df

Multivariate Statistical Analytics & Visual Dashboard

Curriculum Module: 03 — Data Visualization • Stack: Matplotlib, Seaborn, Pandas

A comprehensive visualization platform incorporating multi-panel subplots, side-by-side grouped bars, stacked compositions, bivariate scatter correlation plots, continuous probability density curves (KDE), and categorical box plots formatted for 300 DPI publication standards.

Core Architecture & Deliverables:
  • Dual stacked subplots with customized tick labels and arrow annotations
  • Side-by-side grouped and vertically stacked cumulative bar charts
  • Frequency histograms with superimposed continuous KDE density functions
  • Multi-category box plots depicting medians, IQRs, and statistical outliers
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

def build_multivariate_dashboard(df, x_col, y_col, hue_col):
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    # 1. Scatter with Hue
    sns.scatterplot(data=df, x=x_col, y=y_col, hue=hue_col, ax=axes[0,0])
    # 2. KDE Distribution
    sns.histplot(data=df, x=x_col, hue=hue_col, kde=True, ax=axes[0,1])
    # 3. Categorical Boxplot
    sns.boxplot(data=df, x=hue_col, y=y_col, ax=axes[1,0])
    # 4. Correlation Heatmap
    sns.heatmap(df.select_dtypes(include='number').corr(), annot=True, ax=axes[1,1])
    plt.tight_layout()
    plt.savefig('dashboard_export.png', dpi=300)

Statistical Hypothesis Testing & Inference Framework

Curriculum Module: 04 — Statistical Thinking & Inference • Stack: Python, SciPy, Statsmodels, Pandas

An empirical statistical inference suite that conducts automated parametric and non-parametric testing, including Independent Two-Sample t-tests, One-Way ANOVA across multi-group populations, Pearson correlation significance testing, and Bayesian probability calculations.

Core Architecture & Deliverables:
  • Automated normality checking via Shapiro-Wilk and variance homogeneity via Levene's test
  • Student's t-test and One-Way ANOVA evaluation with automated p-value interpretation
  • Cohen's d effect size measurement and confidence interval bounds estimation
  • Statistical decision-making report generator for academic experimental data
from scipy import stats
import pandas as pd
import numpy as np

def run_hypothesis_pipeline(group_a, group_b, alpha=0.05):
    # Two-sample Independent t-test
    t_stat, p_val = stats.ttest_ind(group_a, group_b)
    
    result = {
        "t_statistic": round(t_stat, 4),
        "p_value": round(p_val, 4),
        "significant": bool(p_val < alpha),
        "decision": "Reject Null Hypothesis" if p_val < alpha else "Fail to Reject Null"
    }
    print(f"Results: t = {result['t_statistic']}, p = {result['p_value']} -> {result['decision']}")
    return result
